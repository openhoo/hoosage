# Hoosage review and repairs — 2026-10-13

## Scope and process

Four agents reviewed the VS Code extension, ingestion and accounting, dashboard,
and standalone JetBrains plugin. Each specialist implemented focused repairs;
independent passes reviewed accounting, source identity, native UI and export
behavior. The coordinator reviewed lifecycle, shared sync, collector boundaries
and packaged artifacts, and ran the final combined qualification.

The clean starting checkout matched `origin/main` at
`87c9ec56550e2e1a80e818ce97f68bafb8508e63` (v0.14.1). Repairs are on
`fix/hoosage-review-20261013`. The baseline had 109 passing JavaScript unit tests.
All telemetry, paths and histories used for regressions were synthetic. No
developer's personal usage or credentials were used as fixtures.

## Confirmed findings and fixes

| Area | Finding and repair |
| --- | --- |
| Transcript reconciliation | A late identity bridge discarded richer metadata from other matched copies. Merge all matched metadata before collapsing aliases, retaining original project/session/time, rich output/cost/duration, and unknown multi-call input. |
| Transcript privacy | An unused `dedupeKey` persisted raw request/message identities. Remove it from calls and caches; keep only allowlisted usage and hashed local aliases. |
| Transcript validation | Far-future timestamps and result arrays were accepted. Validate timestamp range on import/restore and reject non-object completed results. Preserve literal timestamp zero. |
| CLI source deletion | Warm and restored scanners retained usage after the events file or session-state root disappeared. Remove absent source state and cached records. |
| Chat capture deletion | A missing file retained calls, partial bytes and endless indexing. Clear state on ENOENT and allow recreated sources to be read. |
| CLI reported cost | Newly appearing session totals were added to earlier model costs. Reconcile previously accounted model costs with authoritative totals. The regression changes $5.50 to the reported $3.50. |
| CLI estimated cost | Token estimates remained in the sum after an authoritative total arrived. Mark earlier unpriced intervals as included, preserve their unknown individual cost, and suppress another estimate. The regression changes $1.504 to $1.50. |
| CLI checkpoint overlap | Alternating checkpoints and delayed model counters counted the same cost twice. Reconcile checkpoint coverage with cumulative model costs; the mixed $1 → $1.50 → $2 → $2 stream totals $2, previously $2.50. |
| CLI synchronized snapshots | A total-bearing shutdown with a simultaneous model snapshot established a different coverage boundary from a total-only checkpoint. Preserve known residual session cost so a later new model charge is included. |

| CLI decreasing model cost | A decreasing cost snapshot lowered the next increment's baseline. Preserve the prior reliable high-water value while keeping missing/decreasing coverage unknown. |
| CLI reset ordering | A model reset preceding a session-total reset cleared the new model baseline again, duplicating tokens and cost. Retain a baseline already reset against that prior session counter, including across cached restarts. |

## Compatibility and limits

CLI cache format 8 and transcript cache format 3 rebuild older caches without
changing ordinary native CLI or saved project identities. WSL records now carry hashed source
identity; Linux source paths remain local. Covered intervals carry
`costIncludedInSessionTotal: true`; CSV explains the inclusion and individual
cost stays unknown. An older reader does not understand this new provenance.

Legacy shared WSL records lack source-home/distribution provenance and cannot be
safely remapped to the new namespace. Existing shared files retain their normal
independent lifetime; this repair does not rewrite ambiguous historical records.

Deleting a local source clears its warm/cache view. Previously published shared
records retain their existing independent lifetime. Shared peer freshness still
uses filesystem modification times. Token estimates remain a dated bundled
snapshot and USD is observed usage value, not invoice reconciliation.

The VS Code host runs use the installed Insiders binary with isolated profiles
and synthetic telemetry. Windows/WSL behavior is tested with synthetic filesystem
and native-process fixtures on macOS. The JetBrains smoke runs production Swing
components inside IntelliJ's isolated SDK fixture; no ordinary installed IDE
profile or full IDE restart was exercised. Its offscreen Aqua capture has table
header painter limitations and is layout evidence, not full IDE theme proof.

Authenticated Copilot delivery, invoice accuracy and a physical Windows/WSL
session were not exercised. This change prepares reviewed source and installable
candidates; it does not publish a new product version.
